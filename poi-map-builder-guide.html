1. What it does

The POI Map Builder lets you place points of interest (POIs) — hospitals, offices, airports, anything with a location — on an interactive map, label them, and then export the result as a PNG or JPG image you can drop into slides, documents, or emails.

It's a reusable template: build a map once, change the locations whenever you need, and re-export. Your work is saved automatically in your browser, so it's still there when you come back.

2. The screen at a glance

AreaWhat it's for
Top barThe Preset dropdown (ready-made maps), the format dropdown (PNG/JPG), and the Export button.
Left sidebarWhere you build the map: set the title, add locations, and edit each one. This panel is never included in the exported picture.
Map areaThe map itself, with the legend (top-left) and the minimap (bottom-right). This is exactly what gets exported.

3. Quick start

  1. Open the Preset dropdown in the top bar and choose a ready-made map (e.g. “Medical Facilities and Airport”) to see how everything fits together.
  2. Edit the location names, colours, or labels in the left sidebar to match your needs — or delete them and add your own.
  3. Type your Map Title in the sidebar; it appears at the top of the legend.
  4. Choose PNG or JPG in the top bar and click Export.

4. Preset maps

The Preset dropdown holds ready-made maps. Each option is named after the title that appears on its legend. Selecting one loads the whole map — its title, its markers, and its camera angle.

  • Use a preset as a starting point, then edit it.
  • Choosing a preset replaces what's currently on the map, so you'll be asked to confirm if you already have locations. Save first (see Saving & reusing) if you want to keep them.

5. Adding locations

There are two ways to add a location, both in the sidebar's Add Location box:

Click on the map

  1. Click “Click map to add a POI.” The button turns blue to show it's armed.
  2. Click the spot on the map where the location is. A marker drops there.

Enter coordinates

  1. Type a Latitude and Longitude in the two boxes.
  2. Click Add (or press Enter). The boxes clear so you can add several in a row.
Tip: Latitude is between −90 and 90; longitude between −180 and 180. For most places you can copy these from a maps app — they usually look like 43.0621, 141.3517 (latitude first).

7. Map title & legend

The Map Title box in the sidebar sets the heading shown at the top of the legend (the white box on the map). The legend lists every location with its marker and name, and updates automatically as you edit. The legend is included in the exported picture.

8. The minimap

The small map in the bottom-right corner is an overview minimap. It stays centred on the main map so viewers can see where they are in the wider area. Scroll over it to zoom it in or out; it keeps that zoom level as you move the main map. It's included in the exported picture too.

9. Exporting a picture

  1. Frame the map the way you want it (pan/zoom the main map; adjust the minimap).
  2. In the top bar, choose PNG (crisp, best for slides) or JPG (smaller file).
  3. Click Export.
  4. Your browser asks what to share — choose “This Tab.” Confirm.
  5. The image downloads automatically, named after your map title.
Important: When the browser's share prompt appears, pick “This Tab” (not “Entire Screen” or “Window”). This keeps the picture cropped neatly to just the map, legend, and minimap — the sidebar and browser are left out.

10. Saving & reusing

Your map is saved automatically in your browser, so closing and reopening the page keeps your work. To share a map with a colleague or keep a backup, use the buttons at the bottom of the sidebar:

ButtonWhat it does
Save configDownloads a small .json file describing your map (title, locations, view).
Load configOpens a .json file you saved earlier and rebuilds that map.
ResetClears everything to start fresh (asks first).
Make a template: Build a map the way your team likes it, click Save config, and share that file. Anyone can Load config, change the locations, and export — without starting from scratch.

11. Making changes with AI

The map you were given is a single, self-contained HTML file — it holds the map, its styling, and all of its behaviour in one place. That makes it easy to hand to an AI tool and ask for changes in plain English, even if you don't write code yourself.

Tools you can use

  • Claude Code (a terminal app) or Gemini CLI — point them at the HTML file and describe what you want.
  • Claude.ai or the Gemini website — upload or paste the HTML file into the chat and describe the change; it gives you an updated file back.

How to do it

  1. Make a copy first. Always keep the original file safe so you can go back if needed.
  2. Open the file with your AI tool (upload it, paste it, or open the folder in Claude Code / Gemini CLI).
  3. Describe the change in plain English — see example prompts below. Be specific.
  4. Save the file the AI gives back and double-click it to open in your browser to check the result.
  5. If it's not quite right, tell the AI what's still wrong and repeat.

Example requests

What you wantWhat to type to the AI
Change the colour theme“In this HTML file, change the blue accent colour (used in the header bar and buttons) to dark green.”
Change the default title“Change the default map title from ‘My POI Map’ to ‘Regional Offices’.”
Add a satellite map option“Add a dropdown that lets me switch the map between the streets style and a satellite style.”
Move the legend“Move the legend box from the top-left of the map to the top-right.”
Add a new preset map“Add a new preset called ‘European Offices’ with these locations: London 51.5074, −0.1278; Paris 48.8566, 2.3522. Make it appear in the Preset dropdown.”
Good prompts are specific. Mention exact text, colours, and coordinates. Tell the AI it's editing “this single HTML file” and ask it to “return the full updated file.” If something breaks, paste any error message back to the AI.

12. Adding new marker icons with AI

The built-in aeroplane marker is an example of an icon marker. It was created in exactly the way described below — from a screenshot showing the icon that was wanted. You can add more icons (a hospital cross, a hotel bed, a star, etc.) the same way, and they'll then appear as choices in each location's style dropdown, just like “Airport” does today.

Step 1 — Tell the AI which icon you want

You don't need to find or write any code. Use whichever is easiest:

  • Describe it in plain words — e.g. “a hospital cross,” “a hotel bed,” “a coffee cup.”
  • Show it — paste or upload a picture or screenshot of the icon you want. (This is how the aeroplane marker was originally made.)
  • (Optional, for an exact match) If you happen to have an icon from a library such as Lucide, Material Symbols, or Font Awesome, copy its “SVG” and give that to the AI too.

Step 2 — Ask the AI to add it

In this map, marker icons live in a piece of code named ICON_SVG. Mentioning that name helps the AI make the change quickly and consistently with the existing aeroplane. For example:

“In this HTML file, marker icons are defined in a JavaScript object called ICON_SVG, and the aeroplane is selected via the ‘Airport’ option in each location's style dropdown. Please add a new hospital icon the same way — make it match the picture I've given you (or: a simple white medical cross) — add it to ICON_SVG and add a ‘Hospital’ choice to the style dropdown so I can pick it for a location. Make it white and centred inside the pin, matching how the aeroplane looks. Return the full updated file.”

Step 3 — Check it

  1. Open the updated file in your browser.
  2. Add or select a location, open its style dropdown, and choose your new icon.
  3. If the icon looks too big, too small, or off-centre, tell the AI: “the hospital icon is too large and sits high — please centre it and make it a bit smaller,” and it will adjust the sizing.
Why this works: the aeroplane already in the map is a working example the AI can copy. Giving it a picture of the icon you want and asking it to “match how the aeroplane works” is usually all it takes to get a clean result.

13. Tips & FAQ

The map didn't move to my new location

The map auto-frames your locations as you add or remove them. If you've panned away, click a location's number badge to fly back to it.

My exported picture is blank or shows the wrong area

This usually means a different screen/window was shared. Click Export again and choose “This Tab.”

Can I use more than three locations / my own icons / a different map style?

Yes — the tool has no fixed limit on locations. Additional icon types, map styles, or preset maps can be set up by whoever manages your Mapbox account.

Will my work disappear?

It's stored in your browser. Clearing your browser data, or opening the map in a different browser or computer, will start fresh — so use Save config for anything you want to keep permanently.
